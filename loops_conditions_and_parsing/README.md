# 0x04. Loops, conditions and parsing

Description of each script in this directory:

- `1-for_best_school`: displays "Best School" 10 times using a `for` loop.
- `2-while_best_school`: displays "Best School" 10 times using a `while` loop.
- `3-until_best_school`: displays "Best School" 10 times using an `until` loop.
- `4-if_9_say_hi`: displays "Best School" 10 times, printing "Hi" after the 9th iteration.
- `5-4_bad_luck_8_is_your_chance`: loops 1 to 10, printing "bad luck" on 4, "good luck" on 8, "Best School" otherwise.
- `6-superstitious_numbers`: displays 1 to 20, with superstition messages on 4, 9, and 17.
- `7-clock`: displays a clock cycling through hours 0-12 and minutes 1-59.
- `8-for_ls`: lists the current directory's contents, showing only the part of each name after the first dash.
- `9-to_file_or_not_to_file`: reports whether the file `school` exists, is empty, and is a regular file.
- `10-fizzbuzz`: displays numbers 1 to 100 using FizzBuzz rules.
- `11-read_and_cut`: displays username, user ID, and home directory from `/etc/passwd`.
- `12-tell_the_story_of_passwd`: tells a story based on each line of `/etc/passwd`.
- `13-lets_parse_apache_logs`: displays the visitor IP and HTTP status code from an Apache log file.
- `14-dig_the-data`: groups Apache log visitors by IP and HTTP status code, sorted by occurrence count.
